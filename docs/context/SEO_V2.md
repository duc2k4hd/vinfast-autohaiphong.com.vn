# CONTEXT SEO V2 — KẾ THỪA & NÂNG CẤP TỪ NOBIFASHION.VN

## 1. Các Nâng Cấp SEO
- Học hỏi từ `E:\Project\Laravel\nobifashion.vn`:
  - `SeoService` hỗ trợ sinh unique slug, rút gọn trích đoạn sạch HTML, đánh giá điểm SEO theo tiêu chuẩn thẻ title và description.
  - Phân tích nội dung trực tiếp (đếm số từ, ước tính thời gian đọc, mật độ từ khóa).
  - Khai báo đầy đủ các thuộc tính `og:image:width`, `og:image:height`, `og:image:alt`.
  - Giữ vững Structured Data chuẩn ngành đại lý ô tô: `AutoDealer` (Showroom Số 1 Bạch Đằng) và `Car` (Các dòng xe VinFast).
  - Tích hợp thêm HTML Sitemap phục vụ trải nghiệm duyệt web.
