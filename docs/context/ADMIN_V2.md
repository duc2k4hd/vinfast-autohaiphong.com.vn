# CONTEXT ADMIN V2 — PHẦN MỀM QUẢN TRỊ DOANH NGHIỆP

## 1. Triết Lý Quản Trị
Admin được thiết kế như một phần mềm vận hành kinh doanh (Business SaaS) thực thụ:
- Người dùng mục tiêu: Nhân viên kinh doanh, quản lý showroom, biên tập viên nội dung không chuyên về công nghệ.
- Bố cục Sidebar phân nhóm rõ: Tổng quan, Bán hàng (Đơn cọc, Leads), Sản phẩm (Xe, Biến thể), Truyền thông (Bài viết, Media), Cài đặt.
- Bảng dữ liệu chuẩn hóa: Thanh công cụ lọc, tìm kiếm, cột căn lề chuẩn, phân trang giữ bộ lọc, badge trạng thái màu pastel nhạt dễ nhìn.
- Modal xác nhận hành động: Thao tác xóa, hủy, xác nhận thu tiền mặt đều có hộp thoại xác nhận rõ ràng, lịch sự.
